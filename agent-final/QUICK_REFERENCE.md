# 📋 Multi-Project Framework - Quick Cheat Sheet

## Setup (First Time Per Project)

```bash
# 1. Copy framework to your project
cp -r /path/to/template/.agent ./my-project/.agent

# 2. Initialize with /init
cd my-project
/init

# Done! Framework customized for your project
```

## Daily Workflow

```bash
# Plan your work
/start-task

# Implement features (with parallelization)
/implement-feature

# Fix bugs (with auto-approval)
/fix

# Review code
/review

# Monitor progress
orchctl watch workflows
```

## Key Workflows

| Workflow             | Purpose              | When              |
| -------------------- | -------------------- | ----------------- |
| `/init`              | Initialize project   | First time only   |
| `/start-task`        | Plan your work       | Every morning     |
| `/implement-feature` | Build features       | Development       |
| `/fix`               | Fix bugs             | 64% auto-approved |
| `/review`            | Review code          | Before merge      |
| `/test`              | Generate tests       | After feature     |
| `/deploy`            | Deploy to production | Release time      |
| `/doctor`            | Health check         | When unsure       |
