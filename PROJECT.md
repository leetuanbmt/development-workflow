# Gemini CLI Development Workflow

## Project Context
Framework phát triển phần mềm chuẩn hóa (Standardized Development Workflow) dành cho AI-Native Engineering, được thiết kế tối ưu cho Gemini CLI và Google Antigravity.

## Core Identity
- **Name:** Gemini CLI Development Workflow
- **Version:** v5.0.0
- **Type:** AI-Native Framework / Metaproject
- **Primary Goal:** Cung cấp bộ công cụ, quy trình và tiêu chuẩn (Rules, Skills, Workflows) để AI (Lead Engineer) và User (Auditor) phối hợp hiệu quả.

## Technology Stack
- **Core:** Shell Scripting (Bash/Zsh), Markdown (Documentation/Prompts)
- **Supported Stacks:**
  - **Flutter:** (Active) Full support via `stacks/flutter`
  - **Generic:** (Active) Universal workflows via `core`
  - **Node.js / Python:** (Planned) Via extension in `stacks/`

## Key Capabilities
- **Workflow Automation:** `/setup`, `/audit`, `/refactor`, etc.
- **Skill Management:** Proactive skill loading based on context.
- **Memory System:** `.agent/memory/` for persistent context.

## Current Status
Active development (v5.0.0). Focus on multi-project support and stack modularity.
